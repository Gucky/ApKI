# ApKI — Apple Knowledge Index

Use ApKI as a compact routing layer to Apple primary sources. Do not treat its generated indices as a substitute for the linked Apple documentation or video detail page.

## Lookup

- For a WWDC session or another Apple video, start in [references/videos/README.md](references/videos/README.md) to identify the available event and collection files. Then search the individual event and collection files for entries matching the requested topic. Use their titles and descriptions to triage relevance. When a video appears relevant, open its linked Apple video page and inspect the supplementary material: where available, this can include a searchable transcript, code examples, related documentation, sample-code projects, and further Apple resources. Treat the index entry as a routing signal, not the full session content.
- For a framework, API family, or Swift technology, use the alphabetic [framework directory](references/frameworks.md).
- For a common component or API type covered by a technology index, start in [references/technologies/README.md](references/technologies/README.md), then follow the canonical Apple link for detail.
- For HIG, sample code, technology overviews, downloads, or Apple Open Source, use [references/apple-sources.md](references/apple-sources.md).
