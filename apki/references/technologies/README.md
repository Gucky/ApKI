# Technology Component Indexes

Read a technology index when a request names a commonly used component or API type. Each entry is deliberately curated and routes to current Apple documentation; it is not a replacement for the framework’s complete symbol documentation.

- [Swift](swift.md) — core language, standard-library types, Swift 6, and concurrency entry points

- [Foundation](foundation.md) — URLs and networking, data and JSON, files, notifications, dates, localization, and predicates

- [Machine Learning and Charts](machine-learning-and-charts.md) — Core ML and Swift Charts entry points
