# Media and Input Index

Use the matching framework subsection for a named media, camera, analysis, drawing, haptic, or speech type. Per-framework update dates are recorded in [index status](../index-status.json).

## Photos

- Framework: [Photos](https://developer.apple.com/documentation/photos)
- [PHPhotoLibrary](https://developer.apple.com/documentation/photos/phphotolibrary), [PHAsset](https://developer.apple.com/documentation/photos/phasset), [PHFetchResult](https://developer.apple.com/documentation/photos/phfetchresult)

## AVFoundation

- Framework: [AVFoundation](https://developer.apple.com/documentation/avfoundation)
- [AVPlayer](https://developer.apple.com/documentation/avfoundation/avplayer), [AVPlayerItem](https://developer.apple.com/documentation/avfoundation/avplayeritem), [AVCaptureSession](https://developer.apple.com/documentation/avfoundation/avcapturesession), [AVAsset](https://developer.apple.com/documentation/avfoundation/avasset), [AVAssetExportSession](https://developer.apple.com/documentation/avfoundation/avassetexportsession)

## Vision

- Framework: [Vision](https://developer.apple.com/documentation/vision)
- [VNRequest](https://developer.apple.com/documentation/vision/vnrequest), [VNRecognizeTextRequest](https://developer.apple.com/documentation/vision/vnrecognizetextrequest), [VNImageRequestHandler](https://developer.apple.com/documentation/vision/vnimagerequesthandler)

## PencilKit, Core Haptics, and Speech

- [PencilKit](https://developer.apple.com/documentation/pencilkit): [PKCanvasView](https://developer.apple.com/documentation/pencilkit/pkcanvasview), [PKDrawing](https://developer.apple.com/documentation/pencilkit/pkdrawing), [PKToolPicker](https://developer.apple.com/documentation/pencilkit/pktoolpicker)
- [Core Haptics](https://developer.apple.com/documentation/corehaptics): [CHHapticEngine](https://developer.apple.com/documentation/corehaptics/chhapticengine), [CHHapticPattern](https://developer.apple.com/documentation/corehaptics/chhapticpattern)
- [Speech](https://developer.apple.com/documentation/speech): [SFSpeechRecognizer](https://developer.apple.com/documentation/speech/sfspeechrecognizer), [SFSpeechAudioBufferRecognitionRequest](https://developer.apple.com/documentation/speech/sfspeechaudiobufferrecognitionrequest)
