# Developer Tooling

Official tools for formatting, documentation, testing, editors, model conversion, and local development workflows.

- [apple/container](https://github.com/apple/container) — A tool for creating and running Linux containers using lightweight virtual machines on a Mac. It is written in Swift, and optimized for Apple silicon. [Package.swift](https://github.com/apple/container/blob/main/Package.swift)
- [apple/containerization](https://github.com/apple/containerization) — Containerization is a Swift package for running Linux containers on macOS. [Package.swift](https://github.com/apple/containerization/blob/main/Package.swift)
- [apple/coremltools](https://github.com/apple/coremltools) — Core ML tools contain supporting tools for Core ML model conversion, editing, and validation.
- [apple/swift-container-plugin](https://github.com/apple/swift-container-plugin) — Build and publish container images using Swift Package Manager [Package.swift](https://github.com/apple/swift-container-plugin/blob/main/Package.swift)
- [swiftlang/swift-docc](https://github.com/swiftlang/swift-docc) — Documentation compiler that produces rich API reference documentation and interactive tutorials for your Swift framework or package. [Package.swift](https://github.com/swiftlang/swift-docc/blob/main/Package.swift)
- [swiftlang/swift-docc-plugin](https://github.com/swiftlang/swift-docc-plugin) — Swift Package Manager command plugin for Swift-DocC [Package.swift](https://github.com/swiftlang/swift-docc-plugin/blob/main/Package.swift)
- [swiftlang/swift-docc-symbolkit](https://github.com/swiftlang/swift-docc-symbolkit) — A Swift package for encoding and decoding Swift Symbol Graph files. [Package.swift](https://github.com/swiftlang/swift-docc-symbolkit/blob/main/Package.swift)
- [swiftlang/swift-format](https://github.com/swiftlang/swift-format) — Formatting technology for Swift source code [Package.swift](https://github.com/swiftlang/swift-format/blob/main/Package.swift)
- [swiftlang/swift-testing](https://github.com/swiftlang/swift-testing) — A modern, expressive testing package for Swift [Package.swift](https://github.com/swiftlang/swift-testing/blob/main/Package.swift)
- [swiftlang/swiftly](https://github.com/swiftlang/swiftly) — A Swift toolchain installer and manager, written in Swift. [Package.swift](https://github.com/swiftlang/swiftly/blob/main/Package.swift)
- [swiftlang/vscode-swift](https://github.com/swiftlang/vscode-swift) — Visual Studio Code Extension for Swift
