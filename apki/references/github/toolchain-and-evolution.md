# Toolchain and Evolution

Use these repositories for compiler, package-manager, language-server, and language-evolution research. They are not ordinary application dependencies; consult the linked repository and current Swift documentation for the applicable toolchain or proposal state.

## Toolchain and implementation references

- [swiftlang/sourcekit-lsp](https://github.com/swiftlang/sourcekit-lsp) — Language Server Protocol implementation for Swift and C-based languages
- [swiftlang/swift](https://github.com/swiftlang/swift) — The Swift Programming Language
- [swiftlang/swift-corelibs-xctest](https://github.com/swiftlang/swift-corelibs-xctest) — The XCTest Project, A Swift core library for providing unit test support
- [swiftlang/swift-driver](https://github.com/swiftlang/swift-driver) — Swift compiler driver reimplementation in Swift
- [swiftlang/swift-foundation](https://github.com/swiftlang/swift-foundation) — The Foundation project
- [swiftlang/swift-llbuild](https://github.com/swiftlang/swift-llbuild) — A low-level build system, used by Xcode and the Swift Package Manager
- [swiftlang/swift-package-manager](https://github.com/swiftlang/swift-package-manager) — The Package Manager for the Swift Programming Language

## Evolution and experimental watchlist

- [apple/swift-http-api-proposal](https://github.com/apple/swift-http-api-proposal) — This repository contains a proposal for standardized HTTP client and server APIs for the Swift ecosystem
- [apple/swift-network-evolution](https://github.com/apple/swift-network-evolution) — Network protocol stack in Swift for transports like QUIC.
- [swiftlang/swift-evolution](https://github.com/swiftlang/swift-evolution) — This maintains proposals for changes and user-visible enhancements to the Swift Programming Language.
